# 终端解析样例

这些样例保留终端控制序列，用于复现光标定位、分块输入、信任提示识别以及 `/usage` 加载阶段的解析行为，不是账号或会话记录。

路径与会话标识使用 `/Users/example`、`session_REDACTED` 等占位；套餐、模型、用量、时区、重置日期和终端状态均为手写示意内容。百分比统一为 25%，日期使用一月示例，时区为 UTC；这些值没有账号含义。

M6.1 删除了整个用量画像与额度包引导段及装饰性的终端图案，模型宣传、远程控制介绍和信任说明也精简为合成占位文案。保留 ANSI 光标移动、清屏、分块输入，以及提示框的分隔线、`❯`、信任检测关键词；`after-usage.ansi` 保留 Usage 标题、加载提示、额度窗口行和 `Esc to cancel`，用于验证进入 usage 阶段后不会把取消提示误判为首次设置，也不会再次发送命令。删去文案后的光标操作仍由整块、逐字节、7 字节与随机分块测试覆盖；不承诺与原终端录制逐字节一致。
